## Practical Assignment

### Employee Management CLI

A command-line Employee Management application was developed using Python.

The application supports:

* Add Employee
* Update Employee
* Delete Employee
* Search Employee
* List Employees
* Find Highest Salary
* Calculate Average Salary
* Filter Employees by Department

The application uses a list of dictionaries to store employee information and provides a menu-driven command-line interface.
